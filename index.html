DATA NOTES

비교 기준과 주의사항

  • 퍼시픽링스 예약 가격을 기준으로 보여주며 카카오골프·티스캐너 가격은 같은 날짜의 참고값으로 표시합니다.
  • 카카오 1만원 환급은 표시가와 환급 적용가를 함께 보여주며, 비교에는 적용가를 사용합니다.
  • 퍼시픽링스 숫자 가격은 최저가 비교에 포함하며, 금액 미공개 협정가는 별도 배지로 표시하고 순위에서는 제외합니다.
  • 골프공 지급·특가는 카카오골프 목록 또는 상세 조건에서 직접 확인된 해당 날짜에만 표시합니다.
  • 출처 버튼은 세 예약처 모두 표시합니다. 진한 버튼은 해당 가격·혜택의 확인 출처, 옅은 버튼은 해당 날짜의 예약처 조회 화면입니다.
  • 카트비·캐디피 포함 여부와 프로모션 적용 조건은 상품마다 다를 수 있습니다.
  • 표시 가격을 누르면 해당 예약처 화면으로 이동합니다. 예약 상황에 따라 금액이 바뀔 수 있으므로 결제 전 실시간 가격을 최종 확인하세요.
  • 화면은 매일 00:00(KST)에 최신 검증 데이터를 다시 불러옵니다. 로그인 또는 공개 수집이 실패해도 마지막 정상 확인 가격을 유지하며 확인일을 함께 표시합니다.
  • 월·날짜 필터는 12월 31일까지 제공하며, 실제 공개 요금이 검증된 날짜만 가격을 표시합니다.
  • 유사한 골프장명은 자동 부분일치로 합치지 않고, 확인된 동일 명칭만 별칭표로 연결합니다.
